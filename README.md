# HR Analytics Dashboard - Power BI

## Project Overview
Developed an interactive HR Analytics Dashboard using Power BI to analyze employee attrition and workforce trends.

## Tools Used
- Power BI
- DAX
- Excel/CSV Dataset

## KPIs
- Total Employees
- Attrition Count
- Attrition Rate
- Average Age
- Average Salary

## Visualizations
- Attrition by Department
- Attrition by Gender
- Attrition by Job Role

## Features
- Interactive slicers for Department, Gender, and Job Role
- KPI cards for workforce metrics
- Dynamic filtering and analysis

## Key Insights
- Attrition Rate: 16.12%
- Highest attrition observed in Research & Development.
- Laboratory Technicians and Sales Executives showed higher attrition compared to other job roles.
